# Gesture-Based Train Ticket Booking System

This project enables users to book train tickets using **hand gestures** detected via a webcam. It uses **MediaPipe** for hand tracking and **OpenCV** for real-time gesture detection and interaction. The system allows the user to select a destination, number of tickets, ticket class, and confirm the booking—all using hand gestures.

---

## Features

- **Destination Selection** using 0-4 fingers
- **Adult and Child Ticket Count** via finger count
- **Ticket Class Selection**:
  - 1-2 fingers: 2nd Class
  - 3+ fingers: 1st Class
- **Thumbs-Up Gesture** to confirm booking
- Visual display of selected options
- Real-time webcam input and gesture response

---

## Technologies Used

- **Python 3.x**
- **OpenCV** – Real-time video processing
- **MediaPipe** – Hand landmark detection
- **NumPy** – Data operations
